# SyncBoard

SyncBoard is a collaborative task management application being developed as a full-stack group project.

## Assignment 01 - Static Front-End Skeleton

This version contains the initial React frontend skeleton for SyncBoard.

### Current Features

- React frontend created using Vite
- React Router configured
- Login route
- Registration route
- Dashboard route
- Reusable component and page directories prepared

### Project Structure

How to Run

Navigate to the client directory:

cd client

Install dependencies:

npm install

Start the development server:

npm run dev

The application will be available at the local URL shown in the terminal.
